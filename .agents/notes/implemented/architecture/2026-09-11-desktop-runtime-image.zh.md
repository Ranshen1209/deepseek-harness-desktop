# Agent Note：桌面内置运行时、启动动画与保护策略

Status: implemented

[English](2026-09-11-desktop-runtime-image.md) | 中文

## 问题

首次启动重复安装完整依赖会推迟进入主界面。[seed I/O 决策](../bug-fix/2026-09-11-desktop-windows-first-launch.zh.md)减少了重复复制，但仍保留安装工作。只在工具准备阶段检查安全策略，又会在保护插件卸载后留下已准备调用继续执行的窗口。

## 决定

上游 0.1.6 将核心运行时直接置于应用资源与 ASAR，取代旧运行时镜像和维护 seed。启动只创建外部插件 profile 与运行时解析记录，不再为核心运行时执行 pnpm 安装、解压镜像或激活日志。当前运行时归属见[内置运行时决策](2026-09-08-desktop-bundled-runtime-and-external-plugins.zh.md)。

每次进程启动保留已确认的粒子鲸鱼：轮廓就地点亮、整体高亮渐显而非从左到右扫描、不规则星云向外展开。蓝色实体 Logo 仅用于采样且保持隐藏，不渲染 Logo 晕染。鼠标移动影响粒子并产生粒子轨迹，点击释放粒子星芒。固定粒子数量、缓存光点和有界分辨率限制开销；减少动态偏好、隐藏页面、就绪及退出停止动画。进入主界面不等待动画完成，聚焦已运行应用不重播。原生打包在隔离目录启动运行时并检查客户端 HTTP 200，最终 Electron/ASAR 可执行文件还须通过真实会话配合合成模型与审批答复的验收。模块解析遍历 Desktop Host 的完整依赖闭包，包含其私有保护插件；仅遍历 CLI 会遗漏 Host overlay 的依赖。发布前核对精确获批编辑和被拒操作的实际文件结果。

内置 Auto 保护约束所有会话。逐次模型审查通过后自动执行普通工作区编辑，授权不明时单次确认。普通用户主目录可作为工作区，但不允许修改主目录本身；凭据路径段的保护不依赖主目录配置。旧“完全权限”预设保留 ask 策略，不会关闭插件检查。任务授权的外部探针可由模型在提示的临时目录自行选择文本文件名，以独占创建及原文件身份绑定完成可恢复移除。其他外部修改或原有文件移除需要明确用户目标或单次确认。结构化状态检查、恢复验证和有界目录列举提供无需命令的验证路径。不支持的工具 schema 不向模型展示，直接调用仍拒绝。Windows 移除持有源文件及祖先句柄，通过不替换目标的目录句柄相对移动执行；目标变成重解析点时拒绝移动并保留源文件。其他平台没有不安全降级。永久删除和未隔离执行仍禁止。真实祖先目录身份区分 Windows 大小写敏感工作区。固定文件提供者读取冻结条件对象时重新检查授权；受控文件操作还在全部意图监听器返回后重检。宿主准备时记录保护实例，在全部包装器之后、工具函数之前再次核对。持久文件意图检查拦截卸载后的写入，插件先撤销生命周期再移除检查。这些措施不保证在提供者后续每次异步等待或系统发布阶段都能撤销操作。

审核器接受可选字符串说明，但不会将说明视为授权。仅当 DeepSeek 模型的实际能力声明支持时，请求 `max` 思考强度；其他模型保留默认值。桌面审核时限为 120 秒。人工等待不消耗执行窗口，未变化的批准在全部绑定核验后刷新窗口。UI 展示待审批会话及 callId 对应的完整参数；失败只暴露固定诊断分类，不暴露接口原文或凭据。可选的最终可执行文件验收使用确定性任务驱动和 DeepSeek 官方真实审核，逐项核对工具名称及参数哈希，拒绝全部人工审批请求。它验证审核链路。独立可选的自主验收入口使用未改写的中文外部探针请求、真实任务与审核模型、隔离哨兵和独立文件结果检查；它不替代真实按钮或现有用户配置下的安装证据。

桌面发布使用 Node.js 24.19.0 构建，因为 24.17.0 会让 Windows ZIP 解压的 Promise 悬空。上游随包运行时单独固定，仍须通过自身原生依赖与 Host 验收。发布检查还要求内置保护策略的桌面兼容项与发布版本精确一致，然后才开始双平台打包。

## 考虑的替代方案

保留镜像部署会重复上游运行时归属和磁盘工作。固定展示时长拖慢快速机器。仅检查准备阶段无法覆盖卸载窗口；仅替换包装器的取消信号仍可被后续包装器替换。重复全部准备检查会再次消耗单次审批票。

## 影响

核心运行时首次启动无需安装到用户目录。启动窗口仍有必要时才持续播放粒子动画。每次模型审查增加请求延迟和费用，但不能放宽确定性规则。宿主准备、最终执行及文件提交检查在插件卸载后仍存在。策略仍依赖可信宿主与文件系统，不能提供内核级原子文件能力。回归覆盖策略替换、包装器信号替换、精确审批、真实打包 CLI 审查与浏览器粒子交互和退出。
