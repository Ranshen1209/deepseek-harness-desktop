# Agent Note: 桌面采用官方 Auto review

Status: implemented

[English](2026-09-18-desktop-official-auto.md) | 中文

## Problem

自研 preservation 审核器和执行适配引入依赖注入错误，并拒绝原生交付物和子任务工具。额外审批及文件策略接管导致普通 Agent 任务无法完成。用户选择采用官方 Auto 行为，停止继续开发自研策略。

## Decision

桌面通过现有配置条目激活官方实验性 auto-review 插件。审核源码、响应协议、默认思考设置、完全访问执行和取消行为保持原样。自研插件从桌面生产依赖树和构建步骤中移除。保留的可选文件及 Shell 事件没有自研监听器时继续走原生执行。官方插件的[决策](../feature/2026-08-28-auto-review.zh.md)定义审核语义。

本决策替代[此前桌面记录](2026-09-18-desktop-native-auto-approval.zh.md)中的自研 Auto 选择。保存的 preservation 选择解析为 Custom，需要明确重新选择权限。桌面剩余的准入检查只阻止尚未确认的旧权限状态，不审核或限制官方 Auto 的工具。官方启用确认继续显示。新会话默认值仍限于原生档位。

工作区选择及错误处理、启动视觉、资源管理器定位和原生审批通知传输保持不变。现有会话事件读取器兼容以前的自研记录，不重新启用其写入器或策略。

## Alternatives considered

**继续修复自研 Auto。** 用户在普通工具连续运行失败后停止了这条路线。

**把自研实现改名为官方 Auto。** 这样会保留不兼容的执行行为，并误导用户对测试对象的判断。

## Consequences

官方模型批准后直接完全访问执行，没有人工兜底。自研恢复区、确定性文件保护和强制 max 思考设置不再生效；模型可能误判，操作系统权限仍然适用。原生三档保留原有执行规则。

针对性测试覆盖官方审核和旧权限准入。最终包的确定性冒烟覆盖原生读取、搜索、写入、Shell、交付物和子任务审核。真实模型自主规划、GUI 确认、通知投递和安装升级属于独立验收范围；交付证据记录实际执行了哪些检查。
